DESCRIPCION DE UML PROYECTO INTEGRADOR
El diagrama UML representa la estructura principal de una plataforma de gestión para una agencia de seguros. En este modelo se organizan las áreas más importantes del negocio, como la gestión comercial, financiera, reclamos, administración y transformación digital. A través de clases como Cliente, Agente, Póliza, Seguro, Pago, Siniestro y Reclamo, el sistema permite representar los procesos básicos de una aseguradora. Además, se integran clases relacionadas con la transformación digital y la madurez digital, las cuales permiten evaluar el uso de canales digitales, la automatización de procesos, la gestión de indicadores y el nivel de digitalización de la empresa. De esta manera, el proyecto no solo busca organizar la información del negocio, sino también servir como base para una futura plataforma más completa con dashboard, análisis de datos y toma de decisiones empresariales.
